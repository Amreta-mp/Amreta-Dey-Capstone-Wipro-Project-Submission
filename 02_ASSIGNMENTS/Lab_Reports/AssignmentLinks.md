## 📂 Assignment Categories

### Module 1
Foundational automation concepts and initial assignments.

### Milestone 1
Assignments covering the first stage of automation implementation.

### Milestone 2
Assignments involving BDD/API automation using Behave.

### Milestone 3
Assignments focused on **Robot Framework**, including:

- Custom Python keywords
- Assertions
- API testing
- Setup and teardown
- Tags
- Parallel execution
- Reports and logs
